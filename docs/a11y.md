# Accessibility

The target is WCAG 2.1 AA. What enforces it:

| Check                                                                 | Where                                 | Runs                     |
| --------------------------------------------------------------------- | ------------------------------------- | ------------------------ |
| Contrast of every audited colour pair                                 | `apps/web/src/theme/contrast.test.ts` | unit suite, every commit |
| Serious/critical axe violations                                       | `e2e/a11y.spec.ts`                    | `npm run test:e2e`       |
| One `<main>`, a skip link first in the tab order, one `h1`, `img` alt | `e2e/crawl.spec.ts`                   | `npm run test:crawl`     |

`a11y.spec.ts` **fails** on serious and critical. Moderate and minor are
printed on every run and are a backlog, not a free pass.

## Decisions

**The school list is the map's accessible alternative.** There is no way to
make a clustered vector map usable without sight, and an `alt` on a canvas
would be a fiction. Every page that renders a map also renders the same places
as a list, with the same names and addresses, in a form that reads and tabs -
so WCAG 1.1.1 is met by the equivalent, not by the map. The map carries a
visually hidden sentence saying the list is there, because an alternative
nobody is told about is not an alternative. See
`apps/web/src/components/map/MapComponent.tsx`.

**One focus ring, defined once.** `:focus-visible` in `MuiCssBaseline`
(`apps/web/src/theme/components.ts`) rather than per component, because the
failure mode is a component that quietly opts out - which is exactly what the
contact form's textarea did. Suppressing it now has to be deliberate, and there
is one deliberate exception: the `<main>` landmark, which is a focus target for
the skip link rather than a control.

**Icons adjacent to their own label are exempt from 1.4.11.** The search
magnifier, the location pin beside an area name, the contact card icons and the
chip icons all fail 3:1 on `secondary.dark`. They are decorative and the
information is in the text next to them, so they were audited and left alone -
darkening the token would also darken the secondary button's hover fill. The
full list of exemptions, with ratios, is `AUDITED_EXEMPT` in
`apps/web/src/theme/contrast.ts`.

**No document badge, no per-row queries.** Geography rows in the Studio and map
rows here both avoid subtitles that need a fetch per row; the numbers come from
the page's own query instead.

## Dictionary keys

Every user-facing string comes from the Sanity `dictionaries` document, not
from a JSON file in this repo, so a new key has to be added by an editor in the
Studio (Translations → Dictionary). Until it is, next-intl's fallback renders
the key itself - visible and ugly rather than blank, which is deliberate.

These keys are used by this phase's work and **must be added**, with a value
for both `cs` and `en`:

| Key                     | Where it renders                                    | Suggested EN                                                              | Suggested CS                                                     |
| ----------------------- | --------------------------------------------------- | ------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| `skipToContent`         | The skip link, first tab stop on every page         | Skip to content                                                           | Přeskočit na obsah                                               |
| `mapRegionLabel`        | Accessible name of the map region                   | Map of childcare groups                                                   | Mapa dětských skupin                                             |
| `mapListAlternative`    | Visually hidden note beside every map               | Every place on this map is also in the list below, with the same details. | Každé místo na mapě najdete i v seznamu níže, se stejnými údaji. |
| `mapNoResults`          | Shown over the map when filters match nothing       | No places match these filters.                                            | Těmto filtrům neodpovídají žádná místa.                          |
| `closeMapPopup`         | Accessible name of the popup's close button         | Close                                                                     | Zavřít                                                           |
| `noSchoolsFoundHint`    | Under the catalog's empty state                     | Try removing a filter or two.                                             | Zkuste odebrat některý z filtrů.                                 |
| `languageSwitcherLabel` | Accessible name of the language select              | Choose a language                                                         | Zvolte jazyk                                                     |
| `openMenu`              | Accessible name of the mobile hamburger             | Open menu                                                                 | Otevřít menu                                                     |
| `close`                 | Accessible name of the filter dialog's close button | Close                                                                     | Zavřít                                                           |

Already in the dictionary and reused rather than duplicated: `noSchoolsFound`,
`clearAll`, `sending`.
